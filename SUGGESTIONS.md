# Suggestions (not in SPEC.md v1)

Ideas that came up while building. None of these are built. Say the word if you want one.

- **On-screen name switch.** SPEC.md §4a switches names through `nameMode` in `scenario.json`. A small "Real / Fictional names" toggle on screen, or a `?names=fictional` web address option, would make it easier to show both versions in a meeting.
- **Arrow-key shortcuts.** Left and right arrow keys for Back and Next would help someone presenting the demo from a laptop. The buttons already work with Tab and Enter, so this is optional.
- **A publishing workflow.** When you are ready to put the demo on GitHub Pages, a small GitHub Actions file could build and publish it every time you save changes. Nothing is set up for this, and nothing is pushed, as you asked.
